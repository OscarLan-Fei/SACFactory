# Source acknowledgments

SAC-Gen integrates the user-owned PulseICP physical decoder and conditional
residual implementations. The inherited source snapshot, source manifest,
reference identities and license files are retained under sacfactory/_pulseicp.
Public interface names do not replace source attribution.

The implementation uses PyTorch, scikit-learn, NumPy, SciPy, pandas, Streamlit
and Altair. Numerical feature tokenization and Transformer denoising adaptations
retain their method references in the corresponding source files.

Elemental, thermal and chemical-state reference tables retain their source
metadata. Catalogue references identify candidate reagents; actual reagent
declarations and experimental results belong to the researcher.

No citation, model name or source acknowledgment establishes comparative
performance. Cite the relevant methods, software versions and source datasets
when reporting results.
